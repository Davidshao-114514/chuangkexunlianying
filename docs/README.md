## 术语速查

| 缩写 | 含义 | 出现位置 |
|---|---|---|
| BSP | Board Support Package，板级支持层（本工程把硬件操作都收在这一层） | `USER/src/bsp_*.c` |
| DET | Detection，磁吸吸附检测引脚 | 硬件 §4 / 固件 §4 |
| ATIM | Advanced Timer，CW32 高级定时器（本工程的两路 PWM 源） | 固件 §3 |
| CE | Chip Enable，LDO 使能引脚（PB04，整机软开关） | 硬件 §2 / 固件 §5 |
| VBAT | 电池电压（PB00 → ADC_IN7） | 固件 §6 |
| STOP | 停机模式（CPU 停止，可被 GPIO 中断唤醒） | 固件 §5 |
