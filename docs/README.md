## 术语速查

| 缩写 | 含义 | 出现位置 |
|---|---|---|
| BSP | Board Support Package，板级支持层（硬件操作都收在这一层） | `USER/src/bsp_*.c` |
| DET | Detection，磁吸吸附检测引脚 | 硬件 §4 / 固件 §4 |
| ATIM | Advanced Timer，CW32 高级定时器（两路 PWM 源，8kHz） | 固件 §3 |
| CE | Chip Enable，PB04 控制 3V3 轨（磁吸口供电） | 硬件 §2 / 固件 §5 |
| **BGR** | Band Gap Reference，内部 1.2V 基准（用于反推电池电压） | 硬件 §5 / 固件 §6 |
| **CH1115** | 0.5" 88×48 显示屏控制器（不兼容 SSD1306 的 0x8D 命令） | 硬件 §7 |
| **LSI / RTC** | 内部低速时钟 / 实时时钟（用于亮度记忆的时间窗） | 固件 §7 |
| **TGT / G1 / G2** | 屏上显示的「当前调节对象 / 组1 / 组2」状态 | 固件 §2 |
| STOP | 停机模式（CPU 停止，GPIO 中断可唤醒） | 固件 §5 |
| DIM_MIN_PERMILLE | 亮度下限宏（默认 30 = 3%，低于会频闪） | 固件 §2 / §3 |
