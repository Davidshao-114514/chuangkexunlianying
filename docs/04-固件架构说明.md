# 04 · 固件架构说明

> 对应源码：`USER/inc/` + `USER/src/`（12 个 BSP 模块）+ `MDK/Project.uvprojx`（Keil MDK5 + AC6）。
> 阅读顺序：`app_config.h` → `bsp_pin.h` → `main.c` → 各 `bsp_*.c`。

---

## §1 分层结构

```text
main.c / interrupts_cw32l010.c     应用层：UI 布局 / 按键状态机 / 电池状态机 / 主循环
        ▲
bsp_*.c（12 个模块）               板级支持层：一类硬件 = 一个模块
        ▲
CW32L010_Lib/                     芯片标准库（内嵌官方库 + 启动文件 + retarget）
```

| 模块 | 职责 | 教学要点 |
|---|---|---|
| `bsp_pin.h` | **全工程唯一的引脚映射表** | 「引脚改了只改一处」 |
| `app_config.h` | 型号开关（外挂款 / 内置款） | 一套代码覆盖两种产品 |
| `main.c` | UI 布局、按键状态机（单击·长按·双击）、电池状态机、主循环 | 把产品行为与寄存器隔开 |
| `interrupts_cw32l010.c` | BTIM1 1ms 中断入口 → `App_Task1ms()` 调度 | 中断里做什么/不做什么 |
| `bsp_timer.c` | 1ms 系统时基（48MHz/8 = 6MHz，Period 5999） | 软件定时节拍 |
| `bsp_pwm.c` | ATIM PWM：**8kHz / 6000 级**，`BSP_PWM_SetDuty(ch, 千分比)` | 频率与分辨率计算 |
| `bsp_oled.c` | **CH1115 88×48** 驱动（6×8 字库、官方初始化序列） | 屏驱动移植与 UI 排版 |
| `bsp_i2c.c` | 软件 I2C（5µs 时隙 ≈100kHz，地址探测 0x3C–0x3F） | 时序模拟与容错探测 |
| `bsp_adc.c` | 电池电压：**单 BGR 1.2V 反推**（`VBAT = BGR × 4095 / raw_bgr`） | 绝对参考的必要性 |
| `bsp_button.c` | 按键扫描（15ms 去抖，**有效电平宏可配**） | 有效电平与噪声的关系 |
| `bsp_detect.c` | 磁吸吸附检测（外挂款，**100ms 去抖**） | 去抖时间按物理过程定 |
| `bsp_power.c` | **STOP 停机**休眠 + PB03 **上升沿唤醒** | 边沿语义与时序 |
| `bsp_save.c` | **Flash 亮度记忆**（两组亮度 + RTC 时间戳，1h 恢复窗口） | 掉电存储与时间窗设计 |

> **设计哲学**：`main.c` 只表达「产品行为」，不知道寄存器细节；
> 换 MCU 时原则上只重写 `bsp_*`，`main.c` 语义不变。

## §2 按键与复合操作（3 键承载全部功能）

| 按键 | 单击 | 长按（≥300ms） | 双击（≤350ms） |
|---|---|---|---|
| **PB03**（开关机） | 开 / 关机 | — | — |
| **PA04**（亮度 −） | 亮度 −一步 | **连续调暗**（三段加速） | 切换**调节对象**：组A → 组B → 一起（屏显 `TGT`） |
| **PA05**（亮度 +） | 亮度 +一步 | **连续调亮**（三段加速） | 切换**点亮模式**：A 亮 → B 亮 → 一起亮（屏显 `G1/G2 OFF`） |

- 有效电平：**高有效**（外部下拉，抗 PWM 噪声）；
- 去抖：15ms；
- 调光加速曲线：**60ms/步 → 1.1s 后 30ms/步 → 1.9s 后 12ms/步**，步进 **0.5%**；
- 亮度下限：**3%**（宏 `DIM_MIN_PERMILLE`，低于会频闪；可配 0 完全放开）。

> 💡 学习点：**按键越少，语义设计越关键**。把"单击/长按/双击"定义成三种正交语义，
> 就能用 3 个键覆盖 8 个功能——这是消费级产品的常见做法。

## §3 PWM 调光：6000 级是怎么来的

```c
/* bsp_pwm.h */
ARR = 5999;          /* 计数时钟 6MHz? → 见下 */
```

本项目 PWM 计数时钟为 **48MHz**，最终频率与分辨率：

```text
PWM 频率   = 8 kHz        （RY3730 手册推荐 100Hz–10kHz 区间内）
分辨率     = 48MHz / 8kHz = 6000 级   （ARR = 5999）
软件表达   = 千分比 0–1000（默认 100 = 10%），步进 0.5%
占空比换算 = cmp = 千分比 × 6000 / 1000
```

- 通道：PWM1 = PB01 = `ATIM_CH2`（组A）；PWM2 = PA03 = `ATIM_CH3`（组B）；
- 输出条件（外挂款）：**`d = 电源ON × 组点亮 × 亮度 × 已吸附`** 任一为 0 则输出 0。

> 💡 频率与分辨率是一对矛盾（同一计数时钟下频率越高、级数越少）。
> 本项目选择"够用的频率 + 尽量高的级数"，并额外用**软件千分比**统一对外接口，
> 使上层代码与硬件寄存器解耦。

## §4 磁吸检测：去抖与联动

```text
100ms 去抖窗口（比按键的 15ms 长得多——磁吸撞击的机械稳定时间更长）
状态翻转 → 立即 ApplyOutputs()（脱落即灭）→ 置界面刷新请求
```

- 外挂款：`PA01` = 组1、`PA00` = 组2，高 = 已吸附；
- 内置款：整模块编译为空（`#if BSP_DETECT_ENABLED`），输出条件退化为「电源 × 点亮」；
- 未吸附 = 该路输出 0（**安全设计**：避免空载与异常驱动）。

> ⚠️ 常见错误：把检测写成每次轮询直接读电平 → 灯会闪。
> 正确做法：**去抖 + 只在状态翻转时动作**。

## §5 整机开关、低功耗与唤醒（踩坑最多的一处）

```text
关机：CE 拉低（3V3 轨断电）→ 进 STOP（仅保留 GPIO/RTC）
唤醒：PB03 上升沿 → 退出 STOP → 重新使能 HSI → 恢复外设
      → 延时 500 个 1ms 中断后再 OLED_Init（防上电随机亮点）
      → 吞咽窗口内忽略按键（防"唤醒即被再次判为关机"）
```

**四个真实踩过的坑（详见 `docs/08` §3.4）：**

| 现象 | 根因 | 解决 |
|---|---|---|
| 唤不醒 | 唤醒沿方向错（高有效按键需**上升沿**） | 配置上升沿唤醒 |
| 唤醒即重启 | 3V3 未稳时按键扫描误判 | **延迟初始化 + 吞咽窗口** |
| 松手即重启 | 按键**释放回弹**瞬态被当作新唤醒 | 等释放 + 100ms 消抖窗 + **清标志再睡** |
| 关机后开不了机 | PB03 供电随 CE 断开 | 硬件改版：PB3 由 VBAT 分压**常电** |

> 💡 学习点：低功耗调试的坑几乎都在**边沿语义**与**时序**上。
> 另外注意：本项目唤醒后亮度**强制回到 10%**（非关机前值）——若要保持，需改 `main.c` 恢复段。

## §6 电池采样与过放保护状态机（三重设计）

### 6.1 采样

```c
VBAT = BGR × 4095 / raw_bgr;    /* 内部 1.2V 基准反推 VDD；BGR 仅测量时开启 */
```

配套：**成对交替采样**（BGR 与电池通道成对读，抵消 LED 亮灭漂移）+ **IIR 平滑**。
节奏：50ms 一次。详见 `docs/03` §5。

### 6.2 过放保护（阈值 + 滞回 + 确认）

| 状态 | 阈值 | 行为 |
|---|---|---|
| LOW（低电告警） | < **3350 mV**（回升到 3400 mV 解除） | 显示告警页（标题闪烁） |
| PROTECT（过放保护） | < **3200 mV**（回升到 3350 mV 恢复） | **关断输出**，全屏告警 |
| 防抖 | **2s 连续确认** | 防止瞬态误判 |

**告警页交互**：任意键关屏；**1 分钟无操作自动关屏**（省电）。

> 💡 学习点：合格的电池保护必须做到三件事——**滞回**（防抖振）、**确认时间**（防瞬态）、
> **明确的用户可见状态**（告警页）。缺一个都会在真实使用中出问题。

## §7 Flash 亮度记忆（`bsp_save`）

| 项 | 设计 |
|---|---|
| 存储位置 | Flash **第 127 页（0xFE00）**，12 字节记录 + magic 校验 |
| 保存时机 | 亮度变更 **2s 后自动保存**（两组独立）+ **关机时保存** |
| 恢复条件 | 开机时 RTC 时间差 **≤ 1 小时** → 恢复；否则用默认 **10%** |
| 计时源 | 内部 **LSI** 驱动 RTC（无外部晶振） |
| 跨 Reset / 掉电 | Reset 后 RTC 继续走时（可恢复）；**掉电 RTC 归零 → 自然判为超时**（回到默认） |

> 💡 学习点：这是一个非常漂亮的"软性记忆"设计——
> **用时间窗把"想要记忆"和"数据过期"统一到一条判据上**，不需要额外清除逻辑。
> 已知的保守点：跨午夜场景会被判超时（默认 10%），如需精确可扩展日期字段。

## §8 任务调度（全部在 1ms 中断内分频）

| 周期 | 任务 |
|---|---|
| **1ms** | 系统时基、告警页自动关屏倒计时 |
| **5ms** | 按键扫描 + 按键状态机（调光加速 / 双击判定）+ 吸附检测 |
| **50ms** | ADC 电池采样 + 过放保护状态机 |
| **200ms** | 界面数值刷新请求 |
| **主循环** | 只做 OLED 慢速刷屏（耗时 ms 级，不适合放中断） |

> 💡 学习点：`main` 里几乎没有 `while` 阻塞——
> **所有周期性工作交给分频调度，主循环只做"慢活"**，
> 这样既有实时性，又不会因为刷屏破坏时基。

## §9 双型号配置（一行宏切换）

```c
/* USER/inc/app_config.h */
#define PRODUCT_VARIANT_EXTERNAL   0    /* 外挂款：磁吸 4pin + 吸附检测 */
#define PRODUCT_VARIANT_BUILTIN    1    /* 内置款：LED 焊在板上，无需检测 */
#define APP_PRODUCT_VARIANT        PRODUCT_VARIANT_EXTERNAL   /* ← 烧录前改这里 */
```

| 项 | 外挂款 | 内置款 |
|---|---|---|
| `BSP_DETECT_ENABLED` | 1（占用 PA00/PA01） | 0（PA00/PA01 可作按键） |
| 输出条件 | 需「已吸附」 | 仅需「电源 + 点亮」 |
| 按键布局 | 3 键（PB03/PA04/PA05） | 可扩展至 7 键 |

> 💡 学习点：把**产品差异收敛到一个宏**，代码路径共用、测试共用——这是小团队做多 SKU 的标准手段。

## §11 移植与扩展建议

| 想做的事 | 建议起点 |
|---|---|
| 换 MCU | 保留 `main.c` 语义，重写 `bsp_*`；先移植 PWM 与按键 |
| 加蓝牙/串口上报 | 在 200ms 刷新节点挂上报任务（工位数据类项目的基础） |
| 自动调光（环境光感知） | 新增 `bsp_light.c`（光敏 ADC）+ 在 `ApplyOutputs()` 前插入策略，保留手动覆盖 |
| 增加第三路灯组 | 需新增 PWM 通道 + 检测口 + 按键语义（注意引脚余量） |
| 更长的亮度记忆窗口 | 扩展 `bsp_save` 记录结构（增加日期字段解决跨午夜） |
| 唤醒后保持关机前亮度 | 修改 `main.c` 唤醒恢复段（当前固定回 10%） |

## §12 代码风格约定（本包要求）

1. **一个模块一类硬件**：新增硬件 = 新增 `bsp_xxx.c/h`，不在 `main.c` 直接操作寄存器；
2. **引脚只在 `bsp_pin.h` 定义**，其他文件不得出现裸引脚号；
3. **中断里只做短任务**（采样、去抖、置标志），耗时操作交主循环；
4. **产品差异用宏**，不用运行时分支；
5. **注释解释「为什么」**，不复述代码；
6. **可配置项集中化**：亮度下限、恢复窗口、去抖时间、有效电平等都做成宏，便于按硬件适配。
