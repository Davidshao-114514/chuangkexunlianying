# 06 · 测试与验收

> 目的：把「我觉得挺好」变成「有数据、可复核、别人也能复测」。
> 本文所有判据可直接用于教学评分或复现验收（已按最终硬件更新）。

---

## §1 测试环境与工具

| 工具 | 用途 | 可替代方案 |
|---|---|---|
| 万用表 | 电压、电流、通断 | 台式表 |
| 稳压电源（0–10V 可调） | 模拟电池电压做**过放保护**测试 | 可调电池模拟器 |
| 示波器 / 逻辑分析仪 | PWM 频率占空比（8kHz）、无频闪判据 | 手机专业模式/慢动作（仅定性） |
| 测力计（弹簧秤） | 吸附力 | 挂钩 + 砝码逐级加载 |
| 秒表 | 续航计时 | 手机计时 |
| 电子温度计 / 热像仪 | 温升 | 接触式温度探头 |
| 角度尺 / 水平仪 | 悬停漂移 | 目测 + 标记点 |

**记录要求**：室温、湿度、样机编号、固件版本、测试日期——每一项都要写进记录表。

## §2 指标与合格判据（14 项）

| # | 指标 | 测试条件 | 合格判据（建议） |
|---|---|---|---|
| 1 | **吸附力** | 磁吸座吸合标准铁面，垂直加载 | ≥ 设计下限（本项目 2.5kg 级），加载不滑落 |
| 2 | **悬停角度漂移** | 柔臂调至任意角度静置 30 分钟 | 漂移 ≤1°（或标记点目测无明显变化） |
| 3 | **调光无频闪** | **8kHz**，手机摄像头贴近拍摄 | 画面无横向条纹/滚动 |
| 4 | **调光范围与下限** | 0 → 100% 扫描；最低档检查 | 连续可调无死角；**最低亮度 ≥3%**（低于 3% 允许截止，不得频闪） |
| 5 | **两路独立性** | 固定组A 亮度，调组B | 组A 读数与光输出均不变 |
| 6 | **吸附联动** | 点亮状态下取下灯组 | 该组**立即**熄灭 |
| 7 | **未吸附保护** | 不吸灯组开机 | 该路输出为 0（无空载输出） |
| 8 | **关机静态电流** | 关机后静置 1 分钟测电流 | 显著低于开机态（本项目已省去 210µA 分压耗电） |
| 9 | **续航** | 单组满亮度连续点亮 | ≥ 设计目标（按电池容量与驱动效率核算） |
| 10 | **温升** | 满亮度连续 30 分钟 | 外壳/灯头 ≤ 安全上限（不烫手、不光衰） |
| 11 | **电量显示误差** | 稳压源给 3.3 / 3.7 / 4.2 V 三点 | 显示 mV 与标准值误差 ≤ ±3% |
| 12 | **按键功能** | 单击 / 长按（≥300ms）/ 双击（≤350ms）逐项 | 与 `docs/04` §2 功能表完全一致（含三段加速） |
| 13 | **低电保护**（新增） | 稳压源缓慢下调电压 | <3.35V 出 LOW 告警页；<3.2V 关断输出；回升到 3.35V 恢复；2s 确认生效 |
| 14 | **亮度记忆**（新增） | 调亮度 → 关机 → 立刻开机；再等（或改窗口）超 1 小时 | ≤1 小时内开机亮度恢复；超窗口回到默认 10% |

## §3 逐项测试方法（要点）

### 3.1 吸附力（#1）

```text
1) 吸附座吸合基准铁面 → 静置 10 秒；
2) 挂钩挂灯头下方，逐级加砝码（或弹簧秤匀速下拉）；
3) 记录「首次移位/滑落」加载值，重复 3 次取最小。
```

### 3.2 悬停漂移（#2）

```text
1) 柔臂调至水平略上抬，外壳贴标记线并拍照；
2) 静置 30 分钟再拍照对比；
3) 加轻振动（敲击桌面 20 次）后复测，模拟焊接振动。
```

### 3.3 无频闪与最低亮度（#3 / #4）

```text
1) 手机专业模式，快门 ≥1/1000s（或慢动作录像），贴近灯面拍摄 → 8kHz 应无条纹；
2) 对照实验：把 PWM 频率改 1kHz 重烧，应能拍到明显条纹（证明方法有效）；
3) 长按调暗到最低，观察是否在 3% 以下出现闪烁/截止跳变（属预期行为）。
```

### 3.4 吸附联动与未吸附保护（#6 / #7）

```text
1) 点亮灯组 → 取下 → 慢动作录像判读熄灭时刻（目测"即灭"）；
2) 不吸灯组上电，测 PWM 引脚输出 → 应为 0；
3) 反复吸附/脱落 20 次，记录误动作次数（应为 0）。
```

### 3.5 关机静态电流（#8）

```text
1) 电池串入电流表（或用电源电流显示）；
2) 记录开机态电流；PB03 关机后静置 1 分钟再记录；
3) 两者应数量级差异。
```

### 3.6 低电保护（#13）

```text
1) 用稳压电源代替电池；
2) 缓慢下调：记录 LOW 出现电压（期望 3.35V 附近）与 PROTECT 关断电压（期望 3.2V 附近）；
3) 缓慢回升：记录解除告警/恢复输出电压（期望 3.40V / 3.35V，验证滞回）；
4) 快速抖动电压跨越阈值，确认 2s 确认逻辑没有被瞬态触发。
```

### 3.7 亮度记忆（#14）

```text
1) 把两组亮度调到明显不同的值（如 20% / 60%）；
2) 关机 → 立刻开机 → 两组亮度应分别恢复；
3) 使用时间窗验证：超出 1 小时窗口后开机，应回到默认 10%（可临时把窗口宏改小以快速验证）。
```

## §5 教学评分建议

| 维度 | 权重 | 观察点 |
|---|---|---|
| 功能完整（#1/#3/#4/#6/#7/#12） | 35% | 板子是否「能用」，安全逻辑是否生效 |
| 数据可复核（记录表质量） | 20% | 条件、原始数据、结论三要素是否齐全 |
| 指标达标（#2/#5/#8/#10/#11/#13/#14） | 25% | 是否达到判据 |
| 工程规范（接线、焊接、注释） | 10% | 是否可维护、可复现 |
| 反思与改进（提出 ≥1 条改进并验证） | 10% | 是否形成闭环（建议参考 `docs/08` 的踩坑格式） |

## §6 复测须知（保证「稳定复现」）

1. **同一判据、同一条件**：换人复测必须记录环境与工具差异；
2. **失败即记录**：不通过项写明「现象 + 排查过程 + 当时的结论」（本项目 `docs/08` 即由此而来）；
3. **版本对应**：固件 / 外壳 / BOM 三者要能对上（建议样机贴版本号）；
4. **数据留存**：照片与波形按「样机号-测试项-日期」命名归档。
