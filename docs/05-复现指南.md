# 05 · 复现指南（稳定复现是硬指标）

> 本文以「一个没有本项目背景的人，照着做能复现出同样的整机」为目标编写。
> 预计动手时间：PCB 打样等待期 ≈ 3–5 天；实际动手 ≈ 6–10 小时（首次）。

---

## §0 复现路线图

```text
① 采购          BOM 配单（PCBA 器件）+ 磁吸机构 + 打印耗材
                    ↓ （PCB 打样与 3D 打印可并行等待）
② 制板与打印     立创EDA 下单打样 / STEP 切片打印
                    ↓
③ 焊接与装配     按区焊接 → 通电初检 → 装壳 + 磁吸底座
                    ↓
④ 烧录与调试    选型号宏 → SWD 烧录 → 上电自检 → 按排错表处理
                    ↓
⑤ 验收           按 06-测试与验收.md 逐项测并填表
```

## §1 采购清单

### 1.1 PCBA 器件（直接用 BOM）

打开 `工程文件夹/BOM_TYPE-A_PCB2_2026-08-23.xlsx`（34 行 / 56 位号）：
在立创商城「BOM 配单」上传即可自动匹配料号与价格。**替代件选择原则**：

| 器件 | 不可动的关键点 | 可替代的部分 |
|---|---|---|
| 主控 CW32L010F8 | 型号与封装（TSSOP-20）必须一致 | — |
| LDO（ME6211C33 类） | 输出 3.3V、SOT-23-5、**CE 极性**（见 §3 注意） | 其他 3.3V 带使能 LDO |
| 充电/升压管理（IP5306 类） | 与电池、TYPE-C 的配合关系 | 同类移动电源 SOC |
| LED 驱动（SY7200 类） | 升压恒流、PWM 调光频率 ≥20kHz | 同类恒流升压芯片 |
| 阻容（0603/0805） | 值正确即可（电容按 1.3Ω/5.1k/10k/22µF 等对应位号） | 品牌不限 |
| 轻触开关 ×5 | **TS24CA 尺寸**（影响手感与外壳开孔） | 同尺寸贴片轻触 |
| 18650 电池座 | 结构决定（外壳内腔） | 同规格座 |
| TYPE-C 6P | 沉板/立贴形式需与外壳匹配 | 同规格 |

### 1.2 磁吸机构（低成本方案）

| 件 | 要求 | 低成本做法 |
|---|---|---|
| 磁铁 | 直径 20mm 左右，吸力足够（>=3kg 级） | 网购钕铁硼圆片 |
| 底座/法兰 | 与被吸表面（焊台铁质部分）贴合 | 铁片 + 3D 打印座 |
| 柔性臂 | 可定型、悬停不回弹 | 网购定型软管臂；或 3D 打印分段万向节 |
| 灯头连接 | 与 PCB 灯组引出线可靠焊接 | 细硅胶线 + 热缩管 |

### 1.3 工具（一次性投入）

电烙铁（含刀头/尖头）、热风枪（可选）、万用表、稳压电源（调试用）、
SWD 调试器（CW32 配套或通用 DAP）、3D 打印机（或代打印）、镊子、免洗助焊剂、放大镜/台灯。

## §2 制板与打印

1. **PCB**：用立创EDA 专业版打开 `工程文件夹/TYPE-A.epro2` → 检查 DRC → 导出 Gerber → 下单（默认工艺即可，无需阻抗控制）。
2. **3D 打印**：`工程文件夹/3D外壳/*.step` 导入切片软件（FDM 打印建议层高 0.16–0.2mm、壁厚 ≥2 圈、填充 20–30%）。
   外壳配合面若偏紧，用砂纸修整——**不要用蛮力压入 PCB**。
3. **散热片**：优先用随附模型打印后贴装；也可用等厚铝片裁切替换。

---

## §3 焊接与装配

### 3.1 焊接顺序（从低到高、从难到易）

```text
1) 主控 CW32L010F8（TSSOP-20，最难点，先做）
2) 电源区：LDO、充电管理、二极管、电感、电池座
3) 磁吸接口与 LED 驱动区：驱动芯片、磁吸焊盘、检测下拉电阻
4) 阻容小件（0603 优先）
5) 轻触开关 ×5、TYPE-C 座
6) OLED 排针/插座
```

### 3.2 三个必须注意的点

- **⚠️ CE 极性**：换 LDO 型号后，务必确认使能脚是高有效还是低有效，
  并同步修改 `app_config.h` 相邻的 `CE_ACTIVE_LEVEL`（在 `bsp_pin.h` 中定义）；
  若搞反，现象是「一上电就关机」或「关机后仍在耗电」。
- **⚠️ DET 下拉电阻不能省**：漏焊会导致吸附检测随机跳变（灯闪）。
- **⚠️ 磁吸焊盘走线要能过电流**：两组 LED 的回路（LED−）加粗并多打过孔。

### 3.3 通电初检（先不装壳）

1. 只上电不装灯组：测 3V3 是否正常（万用表）；
2. 测 MCU 复位脚电平、SWD 是否可连接；
3. 空载状态下确认**未吸附两路输出为 0**（示波器/万用表看 PWM 脚无输出）。

## §4 烧录

1. 装 **Keil MDK5** + CW32 器件支持包（Cube/器件包按官方说明安装）；
2. 打开 `MDK/` 工程；
3. 打开 `USER/inc/app_config.h`，按你的硬件选择型号：

   ```c
   #define APP_PRODUCT_VARIANT   PRODUCT_VARIANT_EXTERNAL   /* 磁吸外挂款 5 键 */
   /* 或 */                    /* PRODUCT_VARIANT_BUILTIN —— 内置款 7 键 */
   ```

4. SWD 接线：SWCLK = PA08、SWDIO = PA07、GND、3V3（调试器 3.3V）；
5. 编译 → 下载 → 复位；
6. 首次运行预期：OLED 亮起并显示电池电压与两组状态（若 OLED 不亮，见 §5）。

---

## §5 上电自检清单（建议逐项打勾）

- [ ] OLED 显示内容正常，无花屏（花屏多为 IIC 接触不良或 SDA/SCL 接反）
- [ ] BTN1 可开机/关机；关机后按键可唤醒
- [ ] BTN2/BTN3 能改变「当前组」亮度（OLED 数值同步变化）
- [ ] BTN4 能切换当前调节组（组1 ⇄ 组2）
- [ ] BTN5（外挂款：全部亮灭；内置款：组1 亮灭）行为正确
- [ ] 吸附灯组后该组点亮；取下后**立即熄灭**
- [ ] 两路 PWM 互不干扰（分别调亮度，另一路不变）
- [ ] 电池电压显示与万用表读数接近（建议 ≤ ±3%）

## §6 排错表（现象 → 原因 → 处理）

| 现象 | 可能原因 | 处理 |
|---|---|---|
| OLED 全黑 | 供电未到 / IIC 接反 / RST 未释放 | 量 3V3；交换 SDA/SCL 试；检查 PB07 复用 |
| OLED 花屏/闪屏 | IIC 线过长、上拉缺失、软件 IIC 速率过快 | 缩短连线；确认上拉；降低翻转延时 |
| 一上电就关机 | CE 极性配置反了 | 修改 `CE_ACTIVE_LEVEL` |
| 关机后仍耗电 | CE 未真正拉低 / 分压电阻常通 / 驱动使能未关 | 测 CE 电平；检查分压通路；确认驱动 EN |
| 灯不亮（已吸附） | LED 组接线错、LED− 未接到 PWM 低边、恒流芯片未使能 | 量 LED 端电压；检查 LED− 回路 |
| 灯一亮就灭 | 检测误判为「未吸附」（DET 下拉缺失/接触不良） | 检查 DET 与下拉电阻 |
| 灯闪/漂 | 检测无去抖、电源纹波大 | 确认去抖生效；加大输入电容 |
| 亮度跳变不均匀 | 占空比换算取整问题 | 检查 `cmp = 千分数 × 2400 / 1000` 的取整 |
| 按键不响应/连击 | 去抖阈值过小/过大、上拉未生效 | 调整去抖计数；确认 `INPUT_PULLUP` 配置 |
| 唤醒后立刻关机 | 吞键保护被去掉 | 恢复唤醒后 300ms 吞键逻辑 |
| 电量读数偏高/偏低 | 分压比系数错 | 用已知电压校准 `VBAT_DIV_RATIO` |
| 烧录连接失败 | SWD 接线/复位脚被占/时钟配置 | 检查 PA07/PA08；确认 NRST 未被外部拉死 |

## §7 复现成功的最小判据

> 满足以下三条，即认为**复现成功**（可进入 `06` 的完整验收）：
> 1. 整机能开、能关、能被按键唤醒；
> 2. 两组灯可分别独立调光，吸附/脱落联动正确（脱落即灭）；
> 3. OLED 正常显示电池电压、两组亮度与吸附状态。
