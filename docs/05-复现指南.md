# 05 · 复现指南（稳定复现是硬指标）

> 目标：**一个没有本项目背景的人，照着做能复现出同样的整机。**
> 本文已根据项目最终硬件（RY3730 / CH1115 / 3 键 / 电池直供）更新。

---

## §0 复现路线图

```text
① 采购          BOM 配单（PCBA 器件）+ 磁吸机构 + 打印耗材
                    ↓ （PCB 打样与 3D 打印可并行等待）
② 制板与打印     立创EDA 下单打样 / STEP 切片打印（含按键帽）
                    ↓
③ 焊接与装配     按区焊接 → 通电初检 → 装壳 + 按键帽 + 磁吸底座
                    ↓
④ 烧录与调试    选型号宏 → SWD 烧录 → 上电自检 → 按排错表处理
                    ↓
⑤ 验收           按 06-测试与验收.md 逐项测并填表
```

## §1 采购清单

### 1.1 PCBA 器件（直接用 BOM）

打开 `工程文件夹/BOM_TYPE-A_PCB2_2026-08-23.xlsx`（34 行 / 56 位号），
在立创商城「BOM 配单」上传即可自动匹配料号与价格。

| 器件 | 不可动的关键点 | 可替代的部分 |
|---|---|---|
| 主控 **CW32L010F8** | 型号与封装（TSSOP-20）必须一致 | — |
| LED 驱动 **RY3730 ×2** | 调光接口（EN/PWM）、**手册频率区间 100Hz–10kHz** | **SY7200 可 pin-to-pin 替换** |
| 屏 **0.5" CH1115（88×48，I2C）** | 控制器型号（**不兼容 SSD1306 的 0x8D 命令**） | 同尺寸同控制器模块 |
| 充电/升压管理 | 与电池、TYPE-C 的配合关系 | 同类移动电源 SOC |
| 轻触开关 ×3 | 尺寸（影响手感与按键帽） | 同尺寸贴片轻触 |
| 18650 电池座 | 结构决定（外壳内腔） | 同规格座 |
| TYPE-C 6P | 沉板/立贴形式需与外壳匹配 | 同规格 |
| 阻容 | 值正确即可 | 品牌不限 |

> ⚠️ **不要在最终硬件上焊接 10K/10K 电池分压**（本项目已拆除）：那是 210µA 的常通耗电。
> 电池电压改用内部 BGR 反推（见 `docs/03` §5）。

### 1.2 磁吸机构（低成本方案）

| 件 | 要求 | 低成本做法 |
|---|---|---|
| 磁铁 | 直径 20mm 级，吸力足够 | 网购钕铁硼圆片 |
| 底座/法兰 | 与被吸表面（焊台铁质部分）贴合 | 铁片 + 3D 打印座 |
| 柔性臂 | 可定型、悬停不回弹 | 网购定型软管臂 |
| 灯头连接 | 与 PCB 灯组引出线可靠焊接 | 细硅胶线 + 热缩管 |

### 1.3 工具（一次性投入）

电烙铁（刀头/尖头）、热风枪（可选）、万用表、稳压电源（调试）、
SWD 调试器（CW32 配套或通用 DAP）、3D 打印机（或代打印）、镊子、免洗助焊剂、放大镜/台灯。

## §2 制板与打印

1. **PCB**：立创EDA 专业版打开 `工程文件夹/TYPE-A.epro2` → 检查 DRC → 导出 Gerber → 下单（默认工艺即可）。
2. **3D 打印**：`工程文件夹/3D外壳/*.step` 导入切片（FDM 建议层高 0.16–0.2mm、壁厚 ≥2 圈、填充 20–30%）。
   **按键帽也要打印**（3 键手感与防误触）——配合面偏紧用砂纸修整，不要硬压。
3. **散热片**：优先用随附模型；也可用等厚铝片裁切替换。

## §3 焊接与装配

### 3.1 焊接顺序（从低到高、从难到易）

```text
1) 主控 CW32L010F8（TSSOP-20，最难点，先做）
2) 电源区：充电管理、二极管、电感、电池座
3) LED 驱动区：RY3730 ×2、磁吸焊盘、检测下拉电阻
4) 阻容小件
5) 轻触开关 ×3、TYPE-C 座
6) 屏 FPC/排针（CH1115 模块）
```

### 3.2 四个必须注意的点

- **⚠️ 检测下拉电阻不能省**：漏焊会导致吸附检测随机跳变（灯闪）；
- **⚠️ 按键下拉电阻（低阻）不可省**：高阻节点会耦合 PWM 噪声 → 误触（`docs/08` §3.5）；
- **⚠️ 磁吸焊盘与 LED− 回路要能过电流**：走线加粗、多打过孔；
- **⚠️ PB03（开关机键）供电要常电**：若随 CE 一起断电，会出现「关机后开不了机」（`docs/08` §3.4）。

### 3.3 通电初检（先不装壳）

1. 上电测 VBAT 与 3V3 轨（3V3 受 CE 控制，开机状态才应有输出）；
2. 测 MCU 复位脚电平、SWD 是否可连接；
3. 未吸附状态下确认两路 PWM 无输出（安全设计正确）。

## §4 烧录

1. Keil MDK5 + **Arm Compiler 6** + 器件包 `WHXY.CW32L010_DFP 1.0.2`；
2. 打开 `MDK/Project.uvprojx`；
3. 按你的硬件选择型号（`USER/inc/app_config.h`）：

   ```c
   #define APP_PRODUCT_VARIANT   PRODUCT_VARIANT_EXTERNAL   /* 磁吸外挂款 */
   /* 或 */                    /* PRODUCT_VARIANT_BUILTIN —— 内置款 */
   ```

4. SWD 接线：SWCLK = PA08 / SWDIO = PA07 / GND / 3V3；
5. 编译（预期 ≈12KB Flash / ≈1.1KB RAM，0 错 0 警告）→ 下载 → 复位；
6. 首次运行预期：屏点亮并显示电池电压与两组状态；上电默认亮度 **10%**（若 1 小时内有关机记录则恢复记忆值）。

> 若编译报 `assert_failed` 未定义：应用侧必须提供该函数（本项目已在 `main.c` 实现）。

## §5 上电自检清单（逐项打勾）

- [ ] 屏正常显示（花屏 → 查 IIC 接触与初始化序列，见排错表）
- [ ] PB03 单击可开机/关机；关机后按键可唤醒
- [ ] PA05 单击亮度 +、长按连续调亮（三段加速）；PA04 反之
- [ ] 双击 PA04 切换调节对象（屏显 `TGT`：组A → 组B → 一起）
- [ ] 双击 PA05 切换点亮模式（A 亮 → B 亮 → 一起亮）
- [ ] 吸附灯组后该组点亮；**取下立即熄灭**
- [ ] 电池电压显示与万用表接近（≤ ±3%）
- [ ] 低电告警：电压 <3.35V 出 LOW 页；<3.2V 关断输出（可用稳压源模拟）
- [ ] 亮度记忆：调亮度 → 关机 → 立刻开机，亮度应恢复
- [ ] 关机静态电流显著低于开机态

## §6 排错表（整合项目真实踩坑）

| 现象 | 根因 | 解决 |
|---|---|---|
| **屏全黑** | CH1115 不认 SSD1306 的 `0x8D` 电荷泵命令；方向/偏移不符 | 用屏厂官方序列：`0x82` IREF + `0xAD 0x8B 0x33` + `A0/C0` + `D3 0x38` |
| **电池读数恒为 3.3V（或满量程一半）** | VBAT 直供导致分压与参考同源，比例测量失效 | 改用内部 **BGR 1.2V 反推 VDD** |
| **LED 亮起后电压乱跳** | 双通道非同时采样撞上 PWM 波动 | **成对交替采样 + IIR 平滑** |
| **低亮度频闪/啸叫** | 调光频率脱离驱动手册推荐区（100Hz–10kHz） | 用 **8kHz** + 亮度下限 **3%** |
| **关机松手即重启** | 按键释放回弹瞬态被当作唤醒沿 | 等释放 + **100ms 消抖窗 + 清标志再睡** |
| **唤不醒** | 唤醒边沿方向错（按键高有效需**上升沿**） | 配置上升沿唤醒 |
| **唤醒即关机/重启** | 3V3 未稳时按键扫描误判 | **延迟初始化 + 吞咽窗口** |
| **关机后开不了机** | PB03 供电随 CE 断开 | 硬件改版：PB03 由 VBAT 分压**常电** |
| **按键误触（PWM 开启后零星触发）** | 高阻节点耦合 PWM 噪声 | **硬件下拉电阻改小**（软件消抖无效） |
| **唤醒后花屏** | 屏幕掉电重启需完整初始化 | **唤醒延时 500×1ms 后重初始化屏** |
| 灯不亮（已吸附） | LED− 回路或驱动 EN 未接通 | 量灯端电压、查驱动使能与 LED− 走线 |
| 灯一亮就灭 | 检测误判为未吸附（DET 下拉缺失/接触不良） | 检查 DET 与下拉电阻 |
| 烧录连接失败 | SWD 接线/复位脚被占 | 检查 PA07/PA08；确认 NRST 未被外部拉死 |

## §7 复现成功的最小判据

> 满足以下三条即认为**复现成功**（可进入 `docs/06` 完整验收）：
> 1. 整机能开、能关、能被按键唤醒（且唤醒不花屏、松手不重启）；
> 2. 两组灯可分别独立调光（含长按连续调光与双击切换），吸附/脱落联动正确（脱落即灭）；
> 3. 屏正常显示电池电压、两组亮度与吸附状态，且低电告警与亮度记忆生效。
