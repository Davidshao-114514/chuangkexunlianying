# 02 · 学习路径（8 个模块 + 踩坑复盘）

> 每个模块 4 段结构：**目标 → 读什么 → 动手做什么 → 检查点（怎么算过关）**
> 全部模块预计 **16–24 学时**；只做软件（用已焊好的板）需 **10–12 学时**。

---

## 模块 1 · 看懂一台整机（1–2 学时）

**目标**：建立「整机分区」思维：电源域 / 主控域 / 输出域 / 人机域。

**读什么**：`系统框图.png`、`03-硬件设计说明.md` §1。

**动手**：打开 `工程文件夹/TYPE-A.epro2`（立创EDA），把元件按四个域归类，自己画一张框图。

**检查点**：
- 能说出四个域各含哪些元件；
- 能指出电池 → MCU 的供电路径，以及 3V3 轨给谁供电；
- 能说出两组 LED 分别由哪两个引脚驱动。

---

## 模块 2 · 供电与软开关（2–3 学时）

**目标**：理解「电池直供 MCU + CE 控 3V3 轨」为什么不加 LDO，以及这么做的代价。

**读什么**：`03` §2、`04` §5、`08` §3.2。

**动手**：
1. 万用表测：电池电压（VBAT）、开机时 3V3 轨电压、关机后 3V3 轨电压；
2. 在代码里找到 CE 控制（`bsp_pin.h` 的 `LDO_CE_Enable/Disable`），观察关机时它被拉低；
3. 关机后测整机静态电流，与开机态对比。

**检查点**：
- 能解释「为什么电池直供会破坏分压测压法」；
- 能说出 CE 控制的到底是什么（3V3 轨 → 磁吸口），不是什么（MCU 供电）；
- 记录：开机电流 / 关机电流，两者应有数量级差异。

---

## 模块 3 · 按键与复合语义（2 学时）

**目标**：掌握「高有效输入 + 去抖 + 单击/长按/双击状态机」。

**读什么**：`04` §2、`USER/src/bsp_button.c`、`main.c` 按键状态机部分。

**动手**：
1. 把去抖阈值改到 2ms，快速抖动按键，复现误触发，再改回 15ms；
2. 实测两种复合操作：长按 PA05（观察三段加速）、双击 PA04（观察屏上 `TGT` 切换）；
3. 把单击/长按的判定时间改一改，理解「手感」是怎么被参数决定的。

**检查点**：
- 能解释「高有效 + 外部下拉」与「低有效 + 内部上拉」的差别，以及本项目为何选前者；
- 能说明三段加速的用意（短促调节精细、长按快速跨越）；
- 3 键的全部功能（含双击）都能正确触发。

---

## 模块 4 · PWM 与无级调光（2–3 学时）

**目标**：理解频率、分辨率、最低占空比的三角权衡。

**读什么**：`04` §3、`03` §6、`08` §3.3。

**动手**：
1. 推导：48MHz / 8kHz = 6000 级（ARR=5999）；
2. 把频率改成 1kHz 与 20kHz 各试一次，用手机摄像头拍灯对比（条纹/闪烁）；
3. 把亮度下限宏 `DIM_MIN_PERMILLE` 从 30（3%）改到 0，观察最低亮度是否频闪。

**检查点**：
- 能说明「为什么最终是 8kHz」——不是越高越好，而是驱动手册推荐区间（100Hz–10kHz）；
- 手机拍摄 8kHz 无可见条纹；1kHz 时可见（证明判据有效）；
- 能解释「为什么需要亮度下限」，并复现下限以下的现象。

---

## 模块 5 · 磁吸检测与安全联动（2–3 学时）

**目标**：掌握「复用引脚 + 100ms 去抖 + 状态联动」。

**读什么**：`04` §4、`USER/src/bsp_detect.c`、`03` §4。

**动手**：
1. 吸附/取下灯组，观察屏上吸附状态与灯光联动；
2. 把检测去抖时间改到与按键相同（15ms），反复快速吸合，观察是否出现误判闪烁；
3. 灯组点亮时拔下（模拟脱落），确认**立即熄灭**。

**检查点**：
- 能画出一组磁吸 4pin 接线并解释 DET 的上下拉关系；
- 能解释「未吸附不输出」是硬件保护（避免空载与异常驱动）；
- **能说明为什么检测去抖（100ms）要比按键（15ms）长得多**（磁吸撞击的机械稳定时间更长）。

---

## 模块 6 · 采样与电池保护状态机（2–3 学时）

**目标**：从「比例测量失效」到「BGR 绝对参考」，再到完整的过放保护状态机。

**读什么**：`03` §5、`04` §6、`08` §3.2。

**动手**：
1. 用稳压源给 3.3 / 3.7 / 4.2V，核对屏上 mV 显示误差（目标 ≤ ±3%）；
2. 缓慢下调电压，记录 LOW 告警与 PROTECT 关断的触发点（期望 3.35V / 3.2V）；
3. 缓慢回升，验证滞回解除（3.40V / 3.35V）；
4. 快速抖动电压跨越阈值，确认 2s 连续确认逻辑生效（不被瞬态触发）。

**检查点**：
- 能解释「VBAT 直供 → 分压与参考同源 → 比例测量失效」的因果链；
- 能说明 BGR、成对交替采样、IIR 平滑各自解决什么问题；
- 过放保护的**阈值 / 滞回 / 确认时间**三个参数都能说出（并知道为什么要滞回）。

---

## 模块 7 · 低功耗与掉电记忆（2–3 学时）

**目标**：会做「关得掉、唤得醒、记得住」的产品级电源管理。

**读什么**：`04` §5 §7、`USER/src/bsp_power.c`、`bsp_save.c`、`08` §3.4。

**动手**：
1. 关机测静态电流；按 PB03 唤醒，确认屏正常（不花屏）；
2. 长按开机按钮再松手，观察是否被误判为「又关一次」（吞咽窗口在起作用）；
3. 把两组亮度调到明显不同（如 20% / 60%），关机→立刻开机，验证恢复；
4. 把恢复窗口宏改小（如 10 秒），验证「超窗口 → 回到默认 10%」。

**检查点**：
- 能说出低功耗的四个坑（唤醒沿方向、唤醒时序、按键回弹、PB03 供电）及各自解法；
- 能解释唤醒后为什么需要延迟初始化（防上电随机亮点）；
- 能说明 Flash 记忆的「时间窗」设计为什么优雅（无需显式清除过期数据）。

---

## 模块 8 · 结构、装配与验收（2–3 学时）

**目标**：把「能用」变成「好用且可复现」。

**读什么**：`03` §9、`06-测试与验收.md`、`工程文件夹/3D外壳/`。

**动手**：
1. 打印外壳 + **按键帽**（STEP 直接切片），装配 PCBA 与磁吸底座；
2. 按 `06` 的 14 项判据逐项测试并填写记录表；
3. 小组互测：交换样机，用同一判据复测，对比数据差异。

**检查点**：
- 吸附力达到设计下限，悬停不滑落；
- 连续工作温升在安全范围；
- 验收记录表条件、原始数据、结论三要素齐全。

---

## 模块 9（★）· 踩坑复盘（1–2 学时，强烈建议）

**目标**：把别人的坑变成自己的经验——这是本学习包**最值钱的一节**。

**读什么**：`08-开发踩坑实录.md`（全文）。

**动手**：
1. 挑一个坑（如 ADC 三段排查），用自己的话复述「现象 → 假设 → 验证 → 结论」；
2. 在自己的板子上**人为复现**其中一个坑（如把检测下拉电阻拆掉观察灯闪）；
3. 写一条属于你自己的踩坑记录（按 `08` 的表格格式），提交 PR 补充进文档。

**检查点**：
- 能讲清至少 3 个坑的根因（不是背答案，而是理解因果）；
- 能说明「为什么同一个参数（去抖时间/频率）不能一套用到所有地方」；
- 提交了至少 1 条自己的踩坑记录。

## 附录 · 常见学习误区

| 误区 | 正确认识 |
|---|---|
| 「代码能跑就行」 | 12 个 BSP 模块分层的目的：**别人能看懂、能改、能移植** |
| 「PWM 频率越高越好」 | 要看驱动手册推荐区间（本项目 8kHz 就是权衡结果） |
| 「电池电压分压就能测」 | 电池直供时比例测量失效，必须用 BGR 等**绝对参考** |
| 「按键都用内部上拉」 | 高阻节点会耦合 PWM 噪声 → 本项目改用**外部下拉 + 高有效** |
| 「去抖时间统一就行」 | 按键 15ms、磁吸 100ms——**去抖时间由物理过程决定** |
| 「功耗以后再说」 | 电池设备的待机电流决定产品能不能成立（分压电阻就吃掉 210µA） |
| 「踩坑不写下来」 | 本包 `08` 的价值高于代码——同一个坑第二次踩才是真浪费 |
