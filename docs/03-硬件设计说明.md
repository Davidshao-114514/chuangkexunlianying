# 03 · 硬件设计说明

> 数据来源：`工程文件夹/TYPE-A.epro2`（立创EDA 原理图/PCB）、`BOM_TYPE-A_PCB2_*.xlsx`、`USER/inc/bsp_pin.h`（引脚总表）。
> 本文只讲**为什么**——元件的具体参数请对照原理图与 BOM。

---

## §1 系统分区概览

整机按四个域理解（对应 `系统框图.png`）：

| 域 | 包含 | 一句话职责 |
|---|---|---|
| **电源域** | TYPE-C 输入、充电/升压管理、锂电池、3V3 LDO | 让整机「有电、可充、可关断」 |
| **主控域** | CW32L010F8、1ms 时基、复位/调试口 | 决策与调度中心 |
| **输出域** | 双路 PWM → SY7200 恒流 → 两组 LED；磁吸 4pin 接口 | 把电变成「可用的光」 |
| **人机域** | 5/7 个按键、0.91" OLED | 接受操作、反馈状态 |

设计原则：**每个域只通过少数几条线交互**（电源线、PWM、检测、IIC、按键），
这样任何一部分都可以单独替换或升级——例如把 0.91" OLED 换成 1.3"，只影响人机域。

## §2 电源链路

```text
TYPE-C 6P ──▶ 充电/升压管理（IP5306 类，含 4 路电量指示）
                    │
                    ▼
              18650 锂电池（带保护：DW01 + 8205A 类）
                    │
                    ▼
              LDO（ME6211C33 类，SOT-23-5）──3V3──▶ 全系统
                    ▲
                    └── CE（使能）◀── PB04（MCU 输出）
```

**三个关键决策：**

1. **为什么用 LDO 的 CE 脚做整机开关？**
   机械开关要占用结构空间、且无法被程序控制（无法延时关机、无法低电量自动关断）。
   用 PB04 拉高/拉低 CE，等于把「电源开关」变成软件可控：

   ```c
   #define CE_GPIO_PORT   CW_GPIOB
   #define CE_GPIO_PINS   GPIO_PIN_4
   #define CE_ACTIVE_LEVEL 1        /* 1 = 高电平使能；若你的 LDO 相反，改成 0 */
   ```

2. **为什么还要 STOP 停机？**
   CE 拉低后系统掉电，但 MCU 需要「保留唤醒能力」。二者配合：**关机 = CE 拉低 + 进 STOP**，
   整机静态电流降到最低；**唤醒 = 按键中断触发**，恢复后重新使能 HSI 并重新初始化必要外设。

3. **为什么电池采样要接在 MCU 侧（PB00）而不是充电芯片？**
   充电芯片的电量指示是按电压粗略分档（4 格），无法显示具体百分比；
   从电池分压到 MCU 的 ADC 可以自己算 mV 与百分比，**把「电量」变成可编程信息**。

> ⚠️ 复现提示：LDO 的使能极性各厂不同（有的高有效、有的低有效）。
> 换型号后**必须**核对 `CE_ACTIVE_LEVEL`，否则会出现「开机即关机」或「关机后仍耗电」。

## §3 引脚分配总表（CW32L010F8 · TSSOP-20）

> 这张表是全工程的骨架：`bsp_pin.h` 里的宏全部来自它。

| 引脚号 | MCU 引脚 | 功能 | 备注 |
|---|---|---|---|
| 1 | PB04 | **LDO CE**（整机软开关） | GPIO 输出 |
| 2 | PB05 | OLED IIC **SDA** | 软件 IIC |
| 3 | PB06 | OLED IIC **SCL**（丝印 SCK） | 软件 IIC |
| 4 | PB07 / NRST | 系统复位 / OLED RST | 不再作按键 |
| 5 | PA00 (OSC+) | 磁吸接口**组2**吸附检测 | **外挂款**占用于检测；**内置款**作按键 |
| 6 | PA01 (OSC−) | 磁吸接口**组1**吸附检测 | 同上 |
| 10 | PA02 | 按键 BTN1 | 内部上拉，按下低有效 |
| 14 | PA04 | 按键 BTN2 | |
| 15 | PA05 | 按键 BTN3 | |
| 16 | PA06 | 按键 BTN4 | |
| 11 | PB00 (VBAT) | 电池电压采样 | ADC_IN7 |
| 12 | PB01 | **PWM1** = ATIM_CH2 → LED 组1 | 低边开关 |
| 13 | PA03 | **PWM2** = ATIM_CH3 → LED 组2 | 低边开关 |
| 20 | PB03 | 按键 BTN5 | |
| 19 | PB02 | 未引出 | 原理图标 X |
| 17 / 18 | PA08 / PA07 | SWCLK / SWDIO | 调试口 |

**两条设计要点：**

- **不用外部晶振**：内部 HSI 48MHz 已满足 UART/I2C/PWM 精度需求，
  省下 2 个元件、2 个引脚，并把 OSC± 释放给检测功能——这是「引脚不够用」时的典型工程解法。
- **按键数量随型号变化**：外挂款 5 键（PA00/PA01 被检测占用），内置款 7 键。
  同一块 PCB、同一份代码，靠一个宏切换（见 `04` §8）。

## §4 磁吸 4pin 接口与吸附检测（本项目的“招牌设计”）

### 4.1 接口定义（每灯组一个）

| 线序 | 名称 | 说明 |
|---|---|---|
| 1 | **3V3** | 板侧输出 3.3V，供灯端使用 |
| 2 | **GND** | 地 |
| 3 | **LED−** | LED 灯条负极，由 PWM 低边开关驱动 |
| 4 | **DET** | 检测线：灯端把 3V3 接到 DET，吸附后把板侧检测点拉高 |

### 4.2 检测原理（一句话）

> 板侧 DET 有**下拉电阻**（未吸附 = 低电平）；灯端把 3V3 接到 DET（吸附后 = 高电平）。
> MCU 读到高 → 认为「已吸附」，允许输出；读到低 → **切断该路 PWM**。

```c
/* 外挂款：输出 = 电源 ON × 组点亮 × 亮度 × 已吸附 */
d1 = (g_power_on && g_grp1.on && g_det1) ? g_grp1.brightness : 0;
```

### 4.3 为什么这样设计（三个收益）

1. **安全**：灯组脱落瞬间自动灭灯，避免输出端开路/短路造成的异常发热或损坏；
2. **交互自然**：「吸上就亮、取下就灭」，不需要额外开关，符合使用直觉；
3. **可诊断**：吸附状态同时显示在 OLED 上，排障时能立刻区分「灯坏了」还是「没吸好」。

### 4.4 复现注意

- 灯端必须**真正**把 3V3 引到 DET；若灯端只是「短接在一起」而无 3V3 上拉，检测会失效；
- 板侧下拉电阻不可省，否则未吸附时引脚悬空，读数会随机跳变；
- 若你的结构无法引出 DET（例如把 LED 直接焊在板上），请切换到**内置款**配置（见 `04` §8）。

## §5 BOM 与成本（低成本复现的关键）

**物料清单**：`工程文件夹/BOM_TYPE-A_PCB2_2026-08-23.xlsx`（34 行 / 56 个位号，可直接上传立创商城配单）。

成本结构（量产/小批量的粗略口径，仅用于学习估算）：

| 部分 | 说明 | 量级 |
|---|---|---|
| PCBA 器件 | 主控、LDO、充电管理、LED 驱动、阻容、接口 | **≈ ¥25–35** |
| 磁吸机构 | 钕铁硼磁铁 + 柔性臂/金属件 + 底座 | **≈ ¥8–12** |
| 外壳与装配件 | 3D 打印（耗材）+ 螺丝/导热垫 | **≈ ¥5–10** |
| **整机合计** | 不含工具与耗材 | **≈ ¥45 级** |

**低成本复现的四个做法：**

1. **通用件优先**：阻容、LED、轻触开关全部用市面常规料，不做定制；
2. **立创EDA 工程直接下单**：`TYPE-A.epro2` 可一键生成 PCB 订单（打样成本低）；
3. **3D 打印代替开模**：`3D外壳/` 提供 STEP，任何 FDM 打印机可出件；散热片用通用铝片替代亦可用；
4. **主控单型号覆盖两产品**：外挂款/内置款共用一套 PCBA 与固件，摊薄采购与库存风险。

> 💡 想进一步降本：电池可用拆机 18650；接口可用排针代替成品磁吸座（但需自行保证接触可靠）。

## §7 设计决策快问快答

| 问题 | 答复 |
|---|---|
| 为什么不用 DC-DC 而用 LDO？ | 本机电流不大、对噪声敏感（ADC 采样），LDO 简单稳定；若你要驱动更大功率，换 DC-DC 并重新评估 EMI 与纹波。 |
| 为什么 PWM 用 20kHz？ | 高于人眼/摄像头可感频率（无可见频闪），又是驱动芯片规格下限（效率折中）。 |
| 为什么要两路独立 PWM？ | 两组灯可以照不同位置；两路独立亮度才能「指哪照哪」，这是产品体验的核心。 |
| 为什么按键不做成编码器/触摸？ | 焊接场景戴手套、可能有油污与金属屑；机械轻触开关更可靠、成本更低。 |
| 为什么检测要复用到 OSC±？ | 引脚不够（TSSOP-20）＋本机不需要外部晶振——用不到的引脚就是资源。 |
| 电池一定要 18650 吗？ | 不。任何 3.7V 锂电都可（注意容量与放电能力），PCB 上是电池座，改座即可。 |
