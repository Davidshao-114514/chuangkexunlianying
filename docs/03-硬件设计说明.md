# 03 · 硬件设计说明

> 数据来源：`工程文件夹/TYPE-A.epro2`（立创EDA）、`BOM_TYPE-A_PCB2_*.xlsx`、
> `USER/inc/bsp_pin.h`（引脚总表）、`USER/App DEVELOPMENT_SUMMARY.md`（最终硬件配置）。
> 本文只讲**为什么**——元件参数请对照原理图与 BOM。

---

## §1 系统分区概览

| 域 | 包含 | 一句话职责 |
|---|---|---|
| **电源域** | TYPE-C 输入、充电/升压管理、锂电池、3V3 轨（外挂磁吸口供电） | 让整机「有电、可充、可关断」 |
| **主控域** | CW32L010F8（**VBAT 直供**）、1ms 时基、复位/调试口 | 决策与调度中心 |
| **输出域** | 双路 PWM → RY3730 恒流驱动 → 两组 LED；磁吸 4pin 接口 | 把电变成「可用的光」 |
| **人机域** | 3 个按键、0.5" CH1115 屏 | 接受操作、反馈状态 |

设计原则：**每个域只通过少数几条线交互**，任何一部分都可单独替换或升级。

## §2 电源与供电设计（本项目最特殊的一处）

```text
TYPE-C 6P ─▶ 充电/升压管理（含电量指示）─▶ 18650 锂电池
                                              │
                          ┌───────────────────┴────────────────────┐
                          ▼                                        ▼
                 MCU 直接由 VBAT 供电                    3V3 轨（CE=PB04 控制）
                 （无稳压器 · 无外部晶振）                 └─▶ 外挂款磁吸口灯端供电
```

**三个反常识的设计决策（都来自实测）：**

1. **为什么 MCU 由电池直接供电，不加 LDO？**
   CW32L010F8 工作电压范围覆盖锂电区间；去掉 LDO 省元件、省静态电流、省板面积。
   **代价**：不能再用「电源分压 + 同源参考」的方式测电压（见 §5 与 `docs/08` §3.2）。

2. **为什么还要保留 CE（PB04）？**
   CE 控制 **3V3 轨**（外挂款磁吸口的灯端供电）。
   关机时拉低 CE，磁吸口彻底断电——**外接 LED 不耗电、也不会误亮**；
   MCU 自身则进 **STOP** 深度休眠（见 `docs/04` §5）。

3. **为什么按键改成「高电平有效 + 外部下拉」？**
   最终硬件把按键节点做了**低阻下拉**。原因：PWM 开启后，高阻节点会耦合噪声导致误触；
   下拉电阻改小后误触消失。软件侧相应地把有效电平配置为**高有效**
   （`bsp_button` 提供有效电平宏）。

> ⚠️ 复现提示：**"低有效 + 内部上拉"与"高有效 + 外部下拉"是两套完全不同的配置**，
> 抄代码前先确认你的板子是哪种；改错的现象是"按键一直被认为按下"或"完全无响应"。

## §3 引脚分配总表（CW32L010F8 · TSSOP-20 · 最终版）

| 引脚号 | MCU 引脚 | 功能 | 备注 |
|---|---|---|---|
| 1 | PB04 | **CE**：3V3 轨使能（外挂磁吸口供电） | GPIO 输出 |
| 2 | PB05 | 屏 IIC **SDA** | 软件 IIC |
| 3 | PB06 | 屏 IIC **SCL** | 软件 IIC（丝印 SCK） |
| 4 | PB07 / NRST | 系统复位 / 屏 RST | 不作按键 |
| 5 | PA00 (OSC+) | 外挂款：**磁吸组2检测** ／ 内置款：按键 | 复用 OSC 引脚 |
| 6 | PA01 (OSC−) | 外挂款：**磁吸组1检测** ／ 内置款：按键 | 复用 OSC 引脚 |
| 10 | PA02 | 按键（内置款多键配置下使用） | |
| 11 | PB00 (VBAT) | 电池采样位（**最终版改用内部 BGR 反推，10K/10K 分压已拆除**） | 见 §5 |
| 12 | PB01 | **PWM1** = ATIM_CH2 → 组A 驱动 EN | 低边/EN 调光 |
| 13 | PA03 | **PWM2** = ATIM_CH3 → 组B 驱动 EN | 低边/EN 调光 |
| 14 | PA04 | 按键 **亮度 −** | 高有效（外部下拉） |
| 15 | PA05 | 按键 **亮度 +** | 高有效（外部下拉） |
| 16 | PA06 | 按键（内置款多键配置下使用） | |
| 17 / 18 | PA07 / PA08 | SWDIO / SWCLK | 调试口 |
| 19 | PB02 | 未使用（原理图标 X） | |
| 20 | PB03 | 按键 **开关机**（含休眠唤醒） | 高有效；唤醒沿 = **上升沿** |

**两条设计要点：**

- **不用外部晶振**：HSI 48MHz 满足需求，省 2 元件 2 引脚，并把 OSC± 释放给检测/按键；
- **按键数收敛到 3 个**（PB03 / PA04 / PA05）：功能靠「单击 / 长按 / 双击」复合语义承载，
  省引脚、省结构孔位、省 BOM（详见 `docs/04` §2）。

## §4 磁吸 4pin 接口与吸附检测（招牌设计）

### 4.1 接口定义（每灯组一个）

| 线序 | 名称 | 说明 |
|---|---|---|
| 1 | **3V3** | 板侧输出（受 CE 控制），供灯端使用 |
| 2 | **GND** | 地 |
| 3 | **LED−** | LED 灯条负极，由 PWM（EN）驱动 |
| 4 | **DET** | 检测线：灯端把 3V3 接到 DET，吸附后把板侧检测点拉高 |

### 4.2 检测原理

> 板侧 DET 有**下拉**（未吸附 = 低）；灯端 3V3 接 DET（吸附 = 高）。
> MCU 读到高 → 允许输出；读到低 → **切断该路 PWM**。

```c
/* 外挂款：输出 = 电源 ON × 组点亮 × 亮度 × 已吸附 */
d = (g_power_on && grp.on && det) ? grp.brightness : 0;
```

### 4.3 去抖要求（与按键不同！）

吸附检测的**机械抖动比按键更剧烈**（磁铁吸合有撞击、接触弹跳），
本项目最终采用 **100ms 去抖窗口**（按键只需 15ms）。

> 💡 学习点：**去抖时间要按物理过程定**，不能一套参数用到底：
> 磁吸撞击的稳定时间远长于人手按键。

### 4.4 三个收益

1. **安全**：灯组脱落即灭，避免开路/短路异常；
2. **交互自然**：吸上就亮、取下就灭；
3. **可诊断**：吸附状态显示在屏上，能区分"灯坏"与"没吸好"。

## §5 电池电压采样（本项目最大的技术坑）

**最终方案：无外部电路，用内部 BGR（1.2V 基准）反推 VDD。**

```c
VBAT ≈ BGR × 4095 / raw_bgr      /* BGR 通道与待测通道成对采样 */
```

| 方案 | 问题 | 结论 |
|---|---|---|
| VBAT 直供 + 外部 10K/10K 分压 | 分压比与 ADC 参考同源 → **比例测量失效**（读数恒定） | ❌ |
| 分压 + 独立参考 | 可分压电阻**常通耗电 ~210µA** | ❌（电池设备不可接受） |
| **内部 BGR 反推 VDD** | 需要一个绝对参考 | ✅ 最终方案 |

配套三项措施（都在源码里）：
1. **成对交替采样**（BGR 通道与电池通道交替读，消除 LED 亮灭引起的漂移）；
2. **IIR 平滑**（抑制 PWM 引起的电源纹波）；
3. **BGR 仅测量时开启**（进一步省电）。

> ⚠️ 这是复现者最容易翻车的地方：**如果你的板子也是电池直供，别用分压法测电压。**
> 详见 `docs/08` §3.2 的三阶段排查过程。

## §6 输出级与调光参数

| 项 | 参数 | 说明 |
|---|---|---|
| 驱动芯片 | **RY3730 ×2**（可 pin-to-pin 替换 SY7200） | EN/PWM 调光 |
| 调光频率 | **8kHz**（ARR = 5999 → 6000 级） | 手册推荐区间 **100Hz–10kHz** 内 |
| 分辨率 | 6000 级（步进 1/6000 ≈ 0.017%） | 软件以「千分比」表达亮度，步进 0.5% |
| 亮度下限 | **3%**（宏 `DIM_MIN_PERMILLE`，可配 0） | 低于 3% 会频闪 |
| 通道映射 | PWM1 = PB01 = ATIM_CH2（组A）；PWM2 = PA03 = ATIM_CH3（组B） | 两路可独立调节 |

> 💡 与常见教程的差别：**调光频率不是越高越好**。本项目频率经过
> 20k → 30k → 5k → 1k → **8k** 的实测迭代，最终落在驱动芯片手册推荐区间内（见 `docs/08` §3.3）。

## §7 显示屏

| 项 | 参数 |
|---|---|
| 型号 | **0.5" CH1115，88×48 像素**（6 页 × 88 列，6×8 字体） |
| 接口 | 软件 I2C（SCL = PB06、SDA = PB05），地址 **0x3C**（探测 0x3C–0x3F） |
| 尺寸演进 | 0.91"(128×32) → 0.96"(128×64) → **0.5"(88×48)**，UI 重排为 6 行 × 14 字符 |
| 显示内容 | 电池电压/百分比、两组亮度与状态、吸附状态、调节目标（`TGT`）等 |

> ⚠️ CH1115 **不兼容** SSD1306 的 DC-DC 命令（`0x8D`）。初始化序列请以**屏厂官方例程**为准：
> `0x82` IREF + `0xAD 0x8B 0x33` + 方向 `A0/C0` + 偏移 `D3=0x38`（见 `docs/08` §3.1）。

## §8 BOM 与成本（低成本复现的关键）

**物料清单**：`工程文件夹/BOM_TYPE-A_PCB2_2026-08-23.xlsx`（34 行 / 56 位号，可直接立创商城配单）。

| 部分 | 说明 | 量级 |
|---|---|---|
| PCBA 器件 | 主控、充电管理、LED 驱动（RY3730×2）、阻容、接口 | **≈ ¥25–35** |
| 磁吸机构 | 钕铁硼磁铁 + 柔性臂/金属件 + 底座 | **≈ ¥8–12** |
| 外壳与装配件 | 3D 打印（耗材）+ 螺丝/导热垫 + **按键帽** | **≈ ¥5–10** |
| **整机合计** | 不含工具与耗材 | **≈ ¥45 级** |

**低成本复现的四个做法：**

1. **通用件优先**：阻容、LED、轻触开关全用常规料，不做定制；
2. **立创EDA 工程直接下单**：`TYPE-A.epro2` 可一键生成 PCB 订单；
3. **3D 打印代替开模**：`3D外壳/` 提供 STEP（含**按键帽**），FDM 打印机可出件；
4. **驱动可互换**：RY3730 与 SY7200 **pin-to-pin**，缺货时可切换（需同步核对调光频率区间）。

## §10 设计决策快问快答

| 问题 | 答复 |
|---|---|
| 为什么 MCU 直供电池不加 LDO？ | 省电、省件、省面积；代价是只能用 BGR 反推法测电压（§5）。 |
| 为什么调光用 8kHz 而不是 20kHz？ | 驱动手册推荐 100Hz–10kHz；8kHz 在区间内且无可见频闪（低占空比另设 3% 下限）。 |
| 为什么只用 3 个按键？ | 单击/长按/双击语义可覆盖全部功能，省引脚、省结构、省成本（§3）。 |
| 为什么按键是高有效？ | 硬件下拉电阻改小以抗 PWM 噪声，按键因此变成高有效（§2）。 |
| 检测为什么要 100ms 去抖？ | 磁吸撞击的机械稳定时间远长于人手按键（§4.3）。 |
| 为什么不加外部晶振？ | HSI 足够；省 2 元件 2 引脚，OSC± 可复用（§3）。 |
| 电池一定要 18650 吗？ | 不。任何 3.7V 锂电均可（注意容量与放电能力），改电池座即可。 |
