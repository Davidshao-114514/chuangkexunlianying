# 01 · 为什么做这个学习包

## 1. 一个真实的差距

我们团队在完成「磁吸焊接辅助手电」项目时，同时接触了两类东西：

- **一块老师研发的 CW32L010 开发板**：有完整的产品级工程框架（分层 BSP、双型号配置、低功耗、检测保护），但它是为「做出一个东西」准备的；
- **Arduino 生态**：上手极快、教程遍地，但绝大多数项目停留在「传感器 + 模块 + 会亮会动」的层面。

把两者放在一起，差距不在芯片强弱，而在**学习收获的层次**：

| 你会遇到的问题 | Arduino 类开发板 | 本项目的做法 |
|---|---|---|
| 灯怎么亮？ | `digitalWrite(13, HIGH)` 一行搞定 | LDO 软开关 + PWM 恒流驱动 + 20kHz 无频闪 |
| 亮度怎么调？ | `analogWrite()`（约 8 位，低频） | 2400 级、20kHz、双路独立、亮度以千分数表示 |
| 模块没插好怎么办？ | 一般不管 | 磁吸 DET 检测：**未吸附不输出、脱落即灭** |
| 引脚不够用怎么办？ | 换更大的板子 | **复用 OSC±** 两个引脚，兼容两种产品型号 |
| 关机后还耗电吗？ | `delay()` 死循环或直接断电 | LDO CE 拉低 + **STOP 停机**，任意键唤醒 |
| 外壳、装配、成本、测试？ | 不在教学范围内 | 3D 模型 + 装配公差 + BOM 成本 + 验收判据 |

> **启发**：开发板教你「怎么用芯片」，一个**完整产品**才教你「怎么做工程决策」。

由此我们认识到：这样的项目**不应该只停在我们三个人的桌面上**。它需要**开源的共享共建**——
把硬件、固件、结构、测试方法、以及每一个「为什么这样做」都公开出来，
让任何人可以**稳定复现**、并在复现之上继续走远。

## 2. 于是有了这个学习包

### 我们的三个目标

1. **项目式学习**：以「做出一台能用的整机」为目标，而不是以「跑通一个外设实验」为目标。
   学习路径覆盖电源、主控、输出、人机、结构、测试六个层面（见 `02-学习路径.md`）。
2. **稳定复现的低成本结构**：
   - 器件全部是**通用件**（立创商城可直采，替代型号在 `03` §5 给出）；
   - 结构件全部是 **3D 打印 + 通用磁吸五金**，无需开模；
   - 整机 BOM 控制在 **≈ ¥45 级**（不含打印耗材与焊接工具）；
   - 关键参数都给出**判据与测试方法**（见 `06-测试与验收.md`），保证「同样做法、同样结果」。
3. **共享共建**：文档写「为什么」，代码写「怎么」，问题写「坑在哪」——
   让下一个人不必从零踩坑。欢迎提交改进（见 `CONTRIBUTING.md`）。

### 与「教学实验板」的定位差异

- 实验板的目的是**验证知识点**，通常切断真实约束（不管功耗、不管结构、不管成本）；
- 本学习包保留**真实约束**：要低功耗、要装配得上、要便宜、要能量产思考——
  这正是从「学生会做实验」到「工程师能做产品」之间最缺的那一段。

## 3. 这个学习包适合谁

| 读者 | 建议路径 |
|---|---|
| 刚学完 C 语言与单片机基础的同学 | 按 `02-学习路径` 逐模块推进，先跑通外设，再看整机逻辑 |
| 有 Arduino 经验、想进阶的同学 | 重点看 `04-固件架构`（分层 BSP、调度、低功耗）与 `03-硬件设计`（电源与保护） |
| 电子设计竞赛 / 课程设计参赛者 | 直接参考本包的结构设计与测试判据（`03` §4、`06`） |
| 教师 / 社团讲师 | 见 `07-教学设计说明`（课时、检查点、评分建议、教学陷阱） |
| 想做一个类似产品的开发者 | 从 `03-硬件设计说明` 的电源链路与接口定义开始 |

---

## 4. 如何共建（最短版）

```text
发现问题        → 开 Issue（写清环境 + 复现步骤 + 期望结果）
做出改进        → Fork → 新建分支 → 提交 PR（说明「改了什么/为什么/如何验证」）
分享扩展        → 新外壳、新灯组、新交互、移植到其他 MCU 都欢迎
教学复用        → 直接使用 docs/07，注明出处即可
```

> 我们只坚持一件事：**任何改动都应让「下一个人复现」变得更容易，而不是更难。**
