## 一、项目概述

- **产品形态**：双组 LED 灯具（组A / 组B），支持"外挂磁吸款 / 内置款"两种型号软件切换
- **主控**：武汉芯源 CW32L010F8（Cortex-M0+，TSSOP20，64KB Flash / 4KB RAM）
- **供电**：锂电池**直接给 MCU 供电**（VDD = VBAT，无稳压器、无外部晶振）
- **工具链**：Keil MDK5 + Arm Compiler 6（AC6），工程文件 `MDK/Project.uvprojx`
- **依赖**：`CW32L010_Lib/`（内嵌官方标准库 + 启动文件 + retarget）

## 三、软件架构与文件职责

```
USER/inc, USER/src
├── main.c            应用层: UI 布局 / 按键状态机(单击·长按·双击) / 电池状态机 / 主循环
├── interrupts_cw32l010.c  BTIM1 1ms 中断入口 -> App_Task1ms() 调度
├── bsp_timer.c/.h     BTIM1 1ms 系统时基 (48MHz/8=6MHz, Period 5999)
├── bsp_pwm.c/.h       ATIM PWM: 8kHz, BSP_PWM_SetDuty(ch,千分比)
├── bsp_oled.c/.h      CH1115 88×48 驱动 (6x8 字库, 官方初始化序列)
├── bsp_i2c.c/.h       软件 I2C (5µs 时隙≈100kHz, 地址探测 0x3C~0x3F)
├── bsp_adc.c/.h       电池电压: 单 BGR1.2V 反推 (VBAT=BGR×4095/raw_bgr)
├── bsp_button.c/.h    按键扫描 (15ms 去抖, 有效电平宏可配)
├── bsp_detect.c/.h    磁吸吸附检测 (外挂款, 100ms 去抖)
├── bsp_power.c/.h     STOP 停机休眠 + PB03 上升沿唤醒
├── bsp_save.c/.h      Flash 亮度记忆 (两组亮度+RTC 时间戳, 1h 恢复窗口)
├── app_config.h       型号开关: 外挂款 / 内置款
└── main.h / bsp_pin.h 全局声明与引脚映射
```

**中断与任务调度**（全部在 BTIM1 1ms 中断内分频，主循环只做 OLED 慢速刷屏）：
- 1ms：系统时基 / 告警页自动关屏倒计时
- 5ms：按键扫描 + 按键状态机（调光加速/双击判定） + 吸附检测
- 50ms：ADC 电池采样 + 过放保护状态机
- 200ms：界面数值刷新请求

## 四、功能清单与关键参数

| 功能 | 实现要点 |
|---|---|
| 无级调光 | 按住亮度键连续调节，三段加速：60ms/步 → 1.1s 后 30ms/步 → 1.9s 后 12ms/步；步进 0.5% |
| 亮度下限 | 3%（低于 3% 会频闪，宏 `DIM_MIN_PERMILLE` 可调；0=熄灭，与 3% 间跳变） |
| 单击/长按/双击 | 单击=一步微调；长按≥300ms=连续调节；双击（≤350ms）=切换功能 |
| 双击 − | 切换调节对象：A串 → B串 → 一起（屏幕 `TGT` 显示） |
| 双击 + | 切换点亮模式：A亮 → B亮 → 一起亮（屏幕 G1/G2 显示 OFF） |
| 电池保护 | LOW <3350mV（回 3400 解除）；PROTECT <3200mV 关断输出（回 3350 恢复）；2s 连续确认防抖 |
| 告警页 | LOW 标题闪烁 / PROTECT 全屏告警；任意键关屏，1 分钟无操作自动关屏 |
| Flash 记忆 | 亮度变更 2s 后自动保存（两组独立）+ 关机时保存；开机时 RTC 差值 ≤1h 则恢复，否则默认 10% |
| 低功耗 | 关机=CE 断电 + STOP 停机（仅留 GPIO/RTC），PB03 上升沿唤醒；唤醒后延时 500 个 1ms 中断再重初始化屏幕（防随机亮点） |
| 型号切换 | `app_config.h` 单宏切换：外挂款（5 键+检测）/ 内置款（7 键无检测） |

**上电默认**：亮度 10%（或 1h 内恢复值）→ 两组同亮。

## 五、开发经历（简要历程）

### 阶段 1：框架搭建
- 基于 CW32 官方例程（gpio_blink 结构）+ H563 工程的 OLED/I2C 驱动移植
- 建立 UserApp 工程，确定 HSI 48MHz 单时钟方案，ATIM 输出 PWM

### 阶段 2：需求快速迭代
- 按键映射反复调整（7键 → 5键 → 最终 3键：PB03/PA04/PA05）
- 加入磁吸吸附检测、外挂/内置双型号开关
- 建立电池过放保护状态机，阈值两次调整（3.5/3.2 → 3.35/3.2 提高电池利用率）

### 阶段 3：硬件联调攻坚（占开发时间最长）
1. **OLED 点亮马拉松**：经历 4 轮方案——SSD1306 序列 → 网络教程 CH1115 序列 → GitHub 库 → 最终用**商家官方 C51 源码**定位。根因是多处参数差异：方向（A0/C0）、显示偏移（D3=0x38）、电荷泵（0xAD 0x8B 0x33）、IREF（0x82 配置）
2. **ADC 测不准**：
   - 第一阶段：VBAT 直供导致"比例测量失效"（raw 恒为满量程一半）→ 用内部 BGR 1.2V 反推 VDD 解决
   - 第二阶段：LED 点亮后读数漂移 → 双通道成对交替采样 + IIR 平滑
   - 第三阶段：为省电拆除外部 10K 分压（原静态耗电 ~210µA），改为纯 BGR 反推 + BGR 仅测量时开启
3. **频闪/啸叫/功耗调试**：PWM 频率调整史 20k → 30k → 5k → 1k → **8kHz**。根因：RY3730 手册规定调光频率 100Hz~10kHz，超范围或过低都有问题；低占空比频闪最终以 3% 下限 + 8kHz 收尾
4. **休眠唤醒反复踩坑**：
   - "唤不醒"：唤醒沿方向错误（高有效按键需上升沿）
   - "唤醒即重启"：唤醒恢复时序问题（3V3 未稳时按键扫描误判），改为延迟初始化 + 吞咽窗口
   - "松手即重启"：机械按键释放回弹产生瞬态边沿，改为等释放 + 100ms 消抖窗 + 清标志再睡
   - "关机后开不了"：PB3 供电随 CE 断开，下一版硬件改 PB3 由 VBAT 分压常电
5. **按键误触**：无噪声环境正常、PWM 开启后零星误触 → 硬件减小下拉电阻根治（高阻节点抗扰差）

### 阶段 4：体验优化
- 无级调光 + 长按三段加速 + 单击/双击复合功能
- Flash 亮度记忆（RTC 1 小时窗口，跨 Reset 有效；掉电自然过期）
- 屏幕由 0.91"(128×32) → 0.96"(128×64) → 最终 **0.5"(CH1115 88×48)**，UI 全部重排为 6 行×14 字符
- 删除各类调试显示（raw/i12/ST-EV/开机诊断动画），代码瘦身

### 关键踩坑速查表

| 现象 | 根因 | 解决 |
|---|---|---|
| 屏幕全黑 | CH1115 不认 SSD1306 的 DC-DC 命令(0x8D)、方向/偏移错误 | 商家官方序列: 0x82 IREF + 0xAD 0x8B 0x33 + A0/C0 + D3 0x38 |
| 电池读数恒为 3.3V | VBAT 直供 → 分压/参考同源，比例恒定 | 内部 BGR 反推 VDD |
| LED 亮起后电压乱跳 | 双通道非同时采样遇 PWM 波动 | 成对交替采样 + 平滑 |
| 低亮度频闪 | 调光频率脱离 RY3730 推荐区(100Hz-10kHz) | 8kHz + 3% 下限 |
| 关机松手即重启 | 按键释放回弹瞬态被当唤醒沿 | 等释放+消抖窗+清标志 |
| 按键误触 | 高阻节点耦合 PWM 噪声 | 硬件下拉电阻改小 |
| 唤醒后花屏 | 屏幕掉电重启需完整初始化 | 唤醒延时 500 中断后 OLED_Init |

## 六、当前状态与注意事项

- **状态**：全部功能验证通过，编译 0 错误 0 警告；Code ≈12KB / RAM ≈1.1KB
- **注意事项**：
  1. 亮度下限宏 `DIM_MIN_PERMILLE`（默认 30=3%）：低于 3% 频闪，可配为 0 完全放开
  2. Flash 恢复的跨午夜场景保守判超时（按默认 10% 处理），如需精确可扩展日期字段
  3. 外挂款未吸附的组不输出（安全设计）；内置款跳过检测逻辑
  4. 休眠唤醒：唤醒后强制亮度回到 10%（非关机前值），如需保持可修改 main.c 恢复段
  5. `CW32L010_Lib/base_types.h` 中 `USE_FULL_ASSERT` 无条件开启，应用侧必须提供 `assert_failed()`（已在 main.c 实现）
