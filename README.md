## 这是什么？

一块常见的开发板（Arduino / 各类核心板）能教你**外设怎么用**：点亮 LED、读按键、刷 OLED、跑 PWM。
但学完之后，很多人仍然答不上这些问题：

- 一个产品怎么决定用 **LDO 还是 DC-DC**？整机怎么实现**软开关与低功耗**？
- **两路灯组**怎么独立调光、怎么在 20kHz 下做到 2400 级无频闪？
- 外接模块**没插好**时，硬件怎么自我保护（不空载、不烧管）？
- 按键数量不够时，怎么用**复用引脚**兼容两种产品型号？
- 结构、装配、成本、测试…… 这些不写进芯片手册，却是产品与实验的分界线。

**这个学习包就是这些问题的答案。** 它把「磁吸焊接辅助手电」这个真实项目完整开源：
从电源链路到 PWM 调光、从磁吸检测到低功耗、从原理图到 3D 外壳，全部可复现。

### 与「传统开发板」的差别

| 维度 | 传统开发板 / Arduino | 本学习包 |
|---|---|---|
| 学习对象 | 单个外设 Demo | **完整产品链路**（电源→主控→输出→人机→结构） |
| 代码规模 | 示例 sketch / 单个 .c | **分层 BSP 架构**（13 个模块 + 中断分层调度） |
| 硬件决策 | 板载已定，无需思考 | **每个决策都有理由**（LDO 软开关、双路 PWM、复用引脚、检测保护） |
| 产出物 | 一个会闪的灯 | **一台能用的整机**（含外壳、装配、测试表） |
| 复现成本 | 低价但要买全套模块 | **BOM ≈ ¥45 级**，通用件 + 3D 打印结构 |
| 工程习惯 | 少涉及 | 低功耗、去抖、防误触、可维护 BSP 分层 |
| 教学适配 | 课程实验 | **项目式学习**：8 个学习模块、检查点、验收标准 |

> 一句话：**开发板教你「怎么用芯片」，这个学习包教你「怎么做产品」。**

## 快速开始

```text
1. 阅读   docs/01-为什么做这个学习包.md      ← 先看这里（5 分钟）
2. 概览   docs/系统框图.png                  ← 一张图看懂整机
3. 硬件   docs/03-硬件设计说明.md            ← 电源/引脚/磁吸接口/BOM
4. 固件   docs/04-固件架构说明.md            ← 模块划分与调度设计
5. 动手   docs/05-复现指南.md                ← 采购→打样→焊接→烧录→调试
6. 验收   docs/06-测试与验收.md              ← 指标与测试方法
```

**烧录（两种型号，一行宏切换）：**

```c
/* USER/inc/app_config.h */
#define APP_PRODUCT_VARIANT   PRODUCT_VARIANT_EXTERNAL   /* 外挂款：磁吸 LED + 吸附检测（5 键） */
/* #define APP_PRODUCT_VARIANT  PRODUCT_VARIANT_BUILTIN */  /* 内置款：内置 LED（7 键） */
```

Keil MDK5 打开 `MDK/` 工程 → 修改上方宏 → 编译 → 烧录 → 上电自检（OLED 应显示电池电压与两个灯组状态）。

## 仓库结构

```text
├── USER/                    应用固件（分层 BSP，重点学习对象）
│   ├── inc/                 头文件：bsp_pin.h（引脚总表）/ app_config.h（型号开关）/ …
│   └── src/                 bsp_pwm.c（双路调光）bsp_detect.c（磁吸检测）
│                            bsp_power.c（STOP 低功耗）main.c（主逻辑与界面）…
├── MDK/                     Keil MDK5 工程（可直接编译烧录）
├── 工程文件夹/
│   ├── UserApp/             完整工程（含 CW32L010 标准库）
│   ├── BOM_TYPE-A_PCB2_*.xlsx   物料清单（34 行 / 56 位号）
│   ├── TYPE-A.epro2         立创EDA 专业版工程（原理图 + PCB）
│   ├── CW32L010.pdf         主控数据手册
│   └── 3D外壳/              SolidWorks 源文件 + STEP（可直接切片打印）
├── docs/                    学习文档（本学习包的核心）
└── LICENSE                  MIT
```

## 硬核参数（都能在文档里找到依据）

| 项目 | 参数 | 出处 |
|---|---|---|
| 主控 | CW32L010F8，TSSOP-20，HSI 48MHz（**无外部晶振**，省 2 个元件与 2 个引脚） | `docs/03` |
| 调光 | 双路独立 PWM，**20kHz**，48MHz 计数时钟 → **2400 级**（0.1% 步进），无可见频闪 | `docs/04` §3 |
| 调光输出级 | SY7200A（升压恒流）驱动 LED 组，低边 PWM 开关 | `docs/03` |
| 磁吸接口 | 4pin/组：3V3 / GND / LED- / **DET**；吸附才点亮，**脱落即灭** | `docs/03` §4 |
| 吸附检测 | PA00/PA01 **复用 OSC± 引脚**，5ms 采样 + 连续一致去抖 | `docs/04` §4 |
| 整机开关 | **LDO CE（PB04）软开关** + STOP 停机；任意键唤醒 + 300ms 吞键保护 | `docs/04` §5 |
| 电量显示 | PB00 → ADC_IN7（ADCCLK 6MHz、42 周期采样、多次均值）→ OLED 显示 mV/百分比 | `docs/04` §6 |
| 按键 | 外挂款 5 键 / 内置款 7 键（**双型号兼容**，一行宏切换） | `docs/04` §2 |
| 交互 | 0.91" OLED（SSD1306，软件 IIC）；状态：电压、组亮度、吸附状态 | `docs/04` §7 |
| BOM | ≈ ¥45 级整机（PCBA 通用件 + 磁吸机构 + 3D 打印外壳） | `docs/03` §5 |

## 共建共享（Contributing）

这个学习包**欢迎任何人改进**，无论你是学生、教师还是工程师：

- 🐛 **报问题 / 提建议**：开 Issue，说明你的环境与复现步骤
- 🔧 **提交改进**：Fork → 分支 → PR（详见 [CONTRIBUTING.md](CONTRIBUTING.md)）
- 📚 **分享你的扩展**：新外壳、新灯组、新交互、把本包移植到别的 MCU——都欢迎
- 🎓 **教学复用**：教师/社团可直接把 `docs/07` 当课程包使用（含课时与检查点建议）

> 我们相信：**开源不是把代码扔出去，而是让别人能稳定复现、并能在此基础上继续走远。**
> 因此本项目对每一个焊接步骤、每一个参数都注明“为什么”，并把低成本复现作为硬指标。
