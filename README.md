## 这是什么？

一块常见的开发板（Arduino / 各类核心板）能教你**外设怎么用**：点亮 LED、读按键、刷屏、跑 PWM。
但学完之后，很多人仍然答不上这些问题：

- 电池设备为什么敢**不用稳压器**直接给 MCU 供电？那怎么测电池电压？
- 驱动芯片手册写「调光 100Hz–10kHz」，到底该选多少？选错会怎样？
- 按键只有 3 个，怎么覆盖 8 项功能？吸附检测为什么要 100ms 去抖而按键只要 15ms？
- 关机后怎么做到「按键唤醒 + 唤醒不花屏 + 松手不重启」？
- 断电后怎么记住上次亮度，又不会记住"过期的设置"？

**这个学习包就是这些问题的答案**——而且每一个答案都附带**真实踩坑过程**（`docs/08`）。
它把「磁吸焊接辅助手电」这个真实项目完整开源：从电源链路到 PWM 调光、
从磁吸检测到低功耗、从原理图到 3D 外壳，全部可复现。

### 与「传统开发板」的差别

| 维度 | 传统开发板 / Arduino | 本学习包 |
|---|---|---|
| 学习对象 | 单个外设 Demo | **完整产品链路**（电源→主控→输出→人机→结构） |
| 代码规模 | 示例 sketch / 单个 .c | **12 个 BSP 模块 + 1ms 分频调度**（Flash 12KB / RAM 1.1KB） |
| 硬件决策 | 板载已定，无需思考 | **每个决策都有理由**（电池直供、BGR 反推、8kHz、3 键、100ms 去抖） |
| 产出物 | 一个会闪的灯 | **一台能用的整机**（含外壳、按键帽、装配、测试表） |
| 复现成本 | 低价但要买全套模块 | **BOM ≈ ¥45 级**，通用件 + 3D 打印结构 + 驱动可 pin-to-pin 替换 |
| 工程习惯 | 少涉及 | 低功耗时序、去抖、抗噪、掉电记忆、状态机、可维护分层 |
| 真实经验 | 很少有踩坑记录 | **完整踩坑实录**（OLED 四轮点亮、ADC 三段排查、频率五次迭代…） |
| 教学适配 | 课程实验 | **项目式学习**：8 个学习模块、检查点、验收判据 |

> 一句话：**开发板教你「怎么用芯片」，这个学习包教你「怎么做产品」。**

```text
1. 阅读   docs/01-为什么做这个学习包.md     ← 先看这里（5 分钟）
2. 概览   docs/系统框图.png                 ← 一张图看懂整机
3. 硬件   docs/03-硬件设计说明.md           ← 供电/引脚/磁吸接口/BOM
4. 固件   docs/04-固件架构说明.md           ← 模块划分、按键语义、调度、低功耗
5. 踩坑   docs/08-开发踩坑实录.md           ← 强烈建议先读（省几周时间）
6. 动手   docs/05-复现指南.md               ← 采购→打样→焊接→烧录→调试
7. 验收   docs/06-测试与验收.md             ← 指标与测试方法
```

**编译烧录（两种型号，一行宏切换）：**

```c
/* USER/inc/app_config.h */
#define APP_PRODUCT_VARIANT   PRODUCT_VARIANT_EXTERNAL   /* 外挂款：磁吸 LED + 吸附检测 */
/* 或 */                    /* PRODUCT_VARIANT_BUILTIN —— 内置款：内置 LED，无需检测 */
```

Keil MDK5 + **Arm Compiler 6**（需装 `WHXY.CW32L010_DFP 1.0.2`）打开 `MDK/Project.uvprojx`
→ 改宏 → 编译（预期 ≈12KB Flash / ≈1.1KB RAM）→ SWD 烧录 → 上电自检。

## 硬核参数（都能在文档里找到依据与踩坑过程）

| 项目 | 参数 | 出处 |
|---|---|---|
| 主控 | CW32L010F8（Cortex-M0+，TSSOP-20，64KB Flash / 4KB RAM），HSI 48MHz | `docs/03` §3 |
| 供电 | **锂电池直供 MCU**（无稳压器、无外部晶振）；CE 控制 3V3 轨（磁吸口） | `docs/03` §2 |
| 调光 | 双路独立 PWM，**8kHz**，**6000 级**（ARR=5999），软件千分比，步进 0.5%，下限 3% | `docs/04` §3 |
| 驱动 | **RY3730 ×2**（pin-to-pin 可换 SY7200），手册推荐 100Hz–10kHz | `docs/03` §6 |
| 磁吸接口 | 4pin/组：3V3 / GND / LED− / **DET**；吸附才点亮，**脱落即灭** | `docs/03` §4 |
| 吸附检测 | PA01/PA00（复用 OSC±），**100ms 去抖**（按键只需 15ms） | `docs/03` §4.3 |
| 按键 | **3 键**（PB03 开关机 / PA04 亮度− / PA05 亮度+），高有效（外部下拉） | `docs/04` §2 |
| 交互 | 单击 / 长按（≥300ms，三段加速）/ 双击（≤350ms，切对象·切模式） | `docs/04` §2 |
| 电量 | **无外部电路**：内部 BGR 1.2V 反推 VDD + 成对交替采样 + IIR | `docs/03` §5 |
| 电池保护 | LOW <3350mV（回 3400 解除）/ PROTECT <3200mV 关断，2s 确认 + 告警页 | `docs/04` §6 |
| 显示 | 0.5" **CH1115** 88×48，软件 I2C（PB05/PB06，地址 0x3C） | `docs/03` §7 |
| 掉电记忆 | Flash 第 127 页，两组亮度 + RTC 时间戳，**1 小时恢复窗口** | `docs/04` §7 |
| 低功耗 | 关机 = CE 断电 + STOP；PB03 **上升沿**唤醒 + 500ms 延迟初始化 + 吞咽窗口 | `docs/04` §5 |
| 资源占用 | Flash ≈12KB / RAM ≈1.1KB，编译 0 错 0 警告 | `docs/04` §10 |
| BOM | ≈ ¥45 级整机（PCBA 通用件 + 磁吸机构 + 3D 打印外壳） | `docs/03` §8 |

## 共建共享（Contributing）

这个学习包**欢迎任何人改进**，无论你是学生、教师还是工程师：

- 🐛 **报问题 / 提建议**：开 Issue，说明环境与复现步骤
- 🔧 **提交改进**：Fork → 分支 → PR（详见 [CONTRIBUTING.md](CONTRIBUTING.md)）
- 📚 **分享你的扩展**：新外壳、新灯组、新交互、移植到别的 MCU——都欢迎
- 🎓 **教学复用**：教师/社团可直接把 [docs/07](docs/07-教学设计说明.md) 当课程包（含课时与检查点）
- 🧰 **留下你的坑**：把你的踩坑记录补进 [docs/08](docs/08-开发踩坑实录.md)——这比代码更珍贵

> 我们相信：**开源不是把代码扔出去，而是让别人能稳定复现、并能在此基础上继续走远。**
> 因此本项目对每个焊接步骤、每个参数都注明「为什么」，并把低成本复现作为硬指标。
